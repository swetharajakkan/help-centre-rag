**Severity key.** *Embarrasses the client*: something false or unrelated to
their case can be pasted to a customer. *Annoys the user*: the support agent
is blocked and has to go read the article, but nothing wrong leaves the room.

**Fix order.** Mode 1 is first on count (35%) and because its cost is
invisible — the agent is told the corpus is empty and stops looking. Mode 2 is
first on severity and is what the account manager is reporting as "wrong
answers about billing": the answer *contains* the right fix, which is why it
has survived a month of review. Modes 4 and 5 are rarer but land in the same
place as 2, so a fix aimed at extra claims should be measured against all
three.

**Denominator honesty.** 182 traces were generated by replaying a mechanically
built question population through the unmodified assistant; there was no
production trace log to sample. Frequencies are real with respect to that
population and are only as representative as its declared template mix
(`week5/gen_population.py`). Every trace is a genuine system output; none was
written by hand.
